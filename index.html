おかねの図解ノート 制作ツール

YouTube チャンネル「おかねの図解ノート」の運営者が、自分のチャンネルを管理するためだけに使う非公開のツールです。一般の利用者には提供していません。

プライバシーポリシー

最終更新日:2026年10月13日

  • このツールは、チャンネル運営者本人の Google アカウントでのみ YouTube Data API と YouTube Analytics API を使います。
  • 行うこと:運営者が制作した動画・サムネイル・字幕を運営者自身のチャンネルへアップロードすること、運営者自身のチャンネルの統計(再生数・視聴時間・登録者数など)を読み取ること。
  • ログイン情報(OAuth トークン)は運営者のパソコンの中だけに保存します。
  • 他のチャンネルや他の利用者のデータにはアクセスしません。データを第三者に提供・販売することはありません。
  • データの削除:運営者のパソコンに保存したトークンと集計データは、運営者がいつでも削除できます。Google アカウントの権限ページでアクセスを取り消すと、保存済みのトークンは使えなくなります。
  • アクセスの取り消しは Google アカウントの権限ページ からいつでもできます。
  • YouTube API サービスを使用しています。YouTube 利用規約、Google プライバシー ポリシー が適用されます。

Privacy Policy (English)

Last updated: October 13, 2026

"おかねの図解ノート 制作ツール" is a private, single-user tool used only by the owner of the YouTube channel おかねの図解ノート to manage that channel. It is not offered to the public.

  • It uses the YouTube Data API and YouTube Analytics API only with the channel owner's own Google account.
  • It uploads videos, thumbnails and captions created by the owner to the owner's own channel, and reads the owner's own channel statistics (views, watch time, subscribers, etc.).
  • OAuth tokens are stored only on the owner's computer.
  • It does not access data of other channels or users, and no data is shared with or sold to third parties.
  • Data deletion: the OAuth tokens and reports stored on the owner's computer can be deleted by the owner at any time. Revoking access on the Google Account permissions page makes the stored tokens unusable.
  • Access can be revoked at any time from Google Account permissions.
  • This tool uses YouTube API Services. The YouTube Terms of Service and the Google Privacy Policy apply.
